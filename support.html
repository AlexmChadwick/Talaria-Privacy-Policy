Talaria — Support

An iOS client for Hermes Agent, the agent you run on your own computer.

Getting help

Email: fabric-typist.1e@icloud.com — the fastest route, and the one to use for anything involving your own server.

Report a bug: open an issue. Please say which iPhone and iOS version, and how you connect (HTTPS, plain HTTP over Tailscale or a LAN, or SSH).

Talaria needs Hermes Agent running somewhere

Talaria is a client, not a service. It connects to Hermes Agent running on a computer you control. There is no Talaria account and no server in the middle — if you are not running Hermes, there is nothing for the app to connect to.

To see how the app works without setting anything up, open it and tap Look around with sample data on the first screen.

It says it cannot connect

Over plain HTTP, Talaria only connects to addresses that cannot leave a private network: Tailscale (.ts.net and the 100.64.0.0/10 range), your LAN, .local names, and localhost over a forwarded port. Anything else has to be HTTPS, because a token sent in the clear over the open internet is a token somebody else can read. If you typed a public hostname with no scheme, the app assumed HTTP and refused — type https:// explicitly.

Over HTTPS with your own certificate, Talaria will show you the certificate's fingerprint and ask whether to trust it, the same way an SSH client asks about a host key. Once you trust it, that exact certificate is remembered and a different one is refused. If you are reaching the gateway by IP address, note that almost no certificate covers an IP, so this is the path you will take.

Easiest setup for a machine at home: Tailscale, then plain HTTP to the .ts.net name. No certificate needed, and the traffic is encrypted by Tailscale.

The toolbar looks crowded, or a button is missing

Fixed in the first update after 0.1. On a small phone at a large text size the server name could crowd out the buttons beside it. If you are on 0.1, a shorter server name in Settings works around it.

Purchases

Everything in the app works without paying. The unlock changes the colour of your sent messages; the tips are support and unlock nothing on their own, except the three largest, which include the colour unlock and say so. Restore Purchases is on the same screen, at Settings ▸ Help ▸ Extras.

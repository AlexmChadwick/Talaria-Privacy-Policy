# Talaria — Privacy Policy

The privacy policy for [Talaria](https://github.com/NousResearch/hermes-agent), an iOS
client for the self-hosted Hermes Agent. Published here because the App Store requires a
policy at a public URL, and Talaria's own repository is private.

Served at <https://alexmchadwick.github.io/Talaria-Privacy-Policy/>.

`index.html` is the whole thing — one self-contained page, no build step and no external
requests. The source of truth is `PRIVACY.md` in the app's repository; this is generated
from it, so edit that first and regenerate rather than editing here.
